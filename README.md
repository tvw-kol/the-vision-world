# The Vision World — Website

A lightweight, static, Vercel-ready website for The Vision World, Kolkata.

## Production V5

Includes 104 eyewear models, searchable catalogue, optical/sunglasses filters, product detail modal, WhatsApp model enquiries, Meta Pixel, accessibility improvements, FAQ, local-business structured data and a privacy page.

## Deploy on Vercel

1. Create a GitHub repository named `the-vision-world`.
2. Upload all files in this folder to the repository root.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Framework Preset: **Other** (or leave auto-detected).
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Click Deploy.

## Custom domain

Add your domain in Vercel → Project → Settings → Domains.

The site currently uses `https://thevisionworld.in/` in its canonical/SEO settings. Change this in `index.html`, `robots.txt` and `sitemap.xml` if your final domain is different.

## Replace gallery images

The current gallery is intentionally self-contained and uses visual placeholders so the site works immediately. Replace the five `.gallery-item` backgrounds in `styles.css` with your own optimized `.webp`/`.jpg` files when ready.
